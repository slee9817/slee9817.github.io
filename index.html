CHIP-8 / SUPER-CHIP / XO-CHIP Emulator

C++17 · SDL2 · WebAssembly

An emulator for a family of retro virtual machines, written from scratch. It runs classic 1970s games, hi-res SUPER-CHIP games, and modern 4-color XO-CHIP games with programmable sound. It passes a standard opcode test suite, and the same C++ core is compiled to WebAssembly so it runs right in your browser.

SPC Control Chart Tool

Python · Streamlit · pandas · pytest

A statistical process control web app. Load measurement data and it builds I-MR and X̄-R control charts, flags out-of-control signals with the Western Electric rules, and calculates process capability (Cp, Cpk, Pp, Ppk). Every calculation is covered by unit tests with hand-checked expected values, and all sample data is synthetic.

  • SPC
  • Capability
  • Data analysis
  • Unit testing

Don't Touch the Process

JavaScript · HTML Canvas · game design

A browser game that teaches statistical process control. Parts come off a virtual CNC line onto a live control chart while hidden problems (tool wear, bad material, a loose fixture) strike at random. Investigate real signals, leave the noise alone, and get graded at the end of the shift. Reacting to normal variation is penalized as tampering, just like Deming's funnel experiment.
